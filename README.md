# Number Guessing Game (C++)

A C++ game in which the computer selects a random number from 1 to 100 and the player guesses it.

## Features
- Random number generation
- Too High / Too Low hints
- Attempt counter
- Input and range validation
- Winning message

## Run the C++ program
```bash
g++ main.cpp -o guessing_game
./guessing_game
```
On Windows:
```bash
g++ main.cpp -o guessing_game.exe
guessing_game.exe
```

## Colourful web preview
